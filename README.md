# Архитектура личности

Интерактивная игра-опрос для презентации на тему «Факторы развития личности: что делает нас лучше каждый день?».

10 жизненных ситуаций, по 4 варианта ответа. Правильных и неправильных ответов нет: каждый вариант отражает один из четырёх факторов развития личности:

- Наследственность и природные задатки
- Социальная среда
- Воспитание и образование
- Самовоспитание и саморазвитие

В конце игра показывает ведущий фактор участника и процентное распределение всех четырёх. Это образовательная модель индивидуальных приоритетов, а не психологический диагноз.

## Возможности

- Перед началом игры нужно ввести ФИО (минимум фамилию и имя).
- После игры формируется сертификат участника с логотипом университета, ФИО, ведущим фактором и распределением всех четырёх факторов. Его можно скачать в PNG и PDF (A4, альбомная ориентация), поделиться файлом с телефона или отправить ссылку на игру в Telegram, WhatsApp, Facebook, LinkedIn, X и VK.
- Порядок ответов перемешивается в начале каждой игры.
- Кнопки «Назад» и «Далее», автопереход после выбора ответа.
- Результат с кольцевой диаграммой и полосами по каждому фактору; при равенстве показываются все ведущие факторы.
- Режим ведущего: счётчик участников, анонимная статистика, QR-код для подключения, ручное добавление результатов и двухшаговый сброс.
- Светлая и тёмная темы по настройке системы, адаптивная вёрстка для телефонов, ноутбуков и проекторов.

## Запуск

Всё приложение находится в одном файле `index.html` (HTML + CSS + JavaScript без фреймворков). Откройте его в браузере или включите GitHub Pages для этого репозитория.

Статистика ведущего хранится в `localStorage` устройства. Без общего хранилища результаты других участников добавляются вручную кнопками «+ фактор».
